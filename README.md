# Tauminus — Product design

Mockup tương tác và đặc tả chức năng cho workspace terminal tập trung vào AI coding agent, làm việc trên nhiều host và project.

- [Đặc tả chức năng](Tauminus-Product-Design.md): 24 nhóm chức năng, các thao tác và quy tắc nghiệp vụ.
- [Mockup tương tác](Tauminus-Mockup.html): 10 màn hình, gồm workspace desktop/mobile, onboarding, quản lý host, SFTP, vault, forwarding và cộng tác.

## Xem mockup

Tải `Tauminus-Mockup.html` về máy và mở bằng trình duyệt. Có thể tải toàn bộ repo qua **Code → Download ZIP**.

Các thao tác kết nối, chạy agent và truyền file trong mockup là mô phỏng. Đặc tả mô tả chức năng sản phẩm, không xác nhận tình trạng triển khai.
