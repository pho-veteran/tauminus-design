# Tauminus — Product design

Tauminus mở terminal trên máy hiện tại và cho phép thêm host SSH để làm việc với project, coding agent và session từ xa.

- [Đặc tả chức năng](Tauminus-Product-Design.md) mô tả nghiệp vụ sản phẩm và các luồng đã đối chiếu với bản mockup `remote-workbench-haven.zip`.
- [Mockup HTML](Tauminus-Mockup.html) là bản thiết kế trước Haven, gồm 10 màn hình tương tác. Tải file về và mở bằng trình duyệt để xem.
- [Góp ý hoàn thiện mockup](Tauminus-Polish-Feedback.md) là brief dành cho bản thiết kế trước Haven. Các nhận xét trong đó phản ánh bản đã được review ở thời điểm viết.

Mockup dùng dữ liệu mô phỏng cho kết nối, agent và truyền file.
